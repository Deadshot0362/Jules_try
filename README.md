# Mini Chatbot Developer

This project is a Mini Chatbot Developer that lets you highlight FAQs or help articles on websites and auto-generates a Python chatbot using that content. You can export the chatbot code for Flask or Streamlit, or deploy it with one click to Heroku.

## Features

- **Content Extraction:** Extracts the text content from a given URL.
- **Chatbot Generation:** Generates a simple keyword-matching chatbot from the extracted text.
- **Code Export:** Exports the generated chatbot code for Flask and Streamlit.
- **One-Click Deployment:** Deploys the generated chatbot to Heroku with a single click.

## How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python app/main.py
   ```

4. **Open your browser and navigate to `http://127.0.0.1:5000`**

## How to Use

1. **Enter a URL:** Enter the URL of the website with the FAQs or help articles you want to use to generate the chatbot.
2. **Generate Chatbot:** Click the "Generate Chatbot" button to generate the chatbot.
3. **View Chatbot:** The generated chatbot will be displayed on the page.
4. **Export Code:** Click the "Export Flask Code" or "Export Streamlit Code" button to download the generated chatbot code.
5. **Deploy to Heroku:** Click the "Deploy to Heroku" button to deploy the generated chatbot to Heroku.
